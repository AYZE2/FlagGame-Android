Flag Guessing Game
An Android game where players guess countries from their flags, with multiple difficulty levels and a countdown timer for extra challenge.
Features
Multiple game modes / difficulty levels
Countdown timer for added pressure
Game state (score, timer, progress) persists across device orientation changes
Tech Stack
Language: Kotlin
UI: Jetpack Compose
Getting Started
Clone the repo and open it in Android Studio.
Sync Gradle and run on an emulator or physical device.
